04How this becomes a betting input

Use a source hierarchy, then price the matchup. Start with the official VRS and current HLTV snapshot; verify the actual five and map pool; then adjust for recent opponent strength, role changes, veto and schedule. Only compare a bookmaker's implied probability with your own estimate after removing the margin. No TWC odds were published in this snapshot, so there is no price recommendation here.

Base rate

Ranking and opponent-adjusted recent results form the prior. A rank is not a probability.

Lineup state

Apply a continuity adjustment when the five, IGL or coach changed. See the date-stamped tracker.

Map state

Wait for the group draw and veto data. A small Cache sample should widen uncertainty, not create a confident edge.
